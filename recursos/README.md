# Recursos compilados por version

Cada subcarpeta `vX.Y.Z/` contiene una build completa `onedir` de Helpmeet
generada con `scripts/build_dev.ps1`.

Para probar una version: ejecutar `recursos/vX.Y.Z/Helpmeet.exe`.

Las builds de produccion (instalador .exe) se generan con `scripts/build_release.ps1`
y van a `dist/installer/`.
